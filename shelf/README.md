# Shelf

Skills and ideas kept for a future need and not used now (Jase, 2026-11-22). Nothing here is a plugin or sits in a skills folder, so no session, app or Codex run loads it, and it costs no tokens until someone reads it on purpose.

**Using one.** It comes off the shelf only as a proposal to the owner that names the need. Then it moves into a plugin, gets a `THIRD_PARTY.md` entry and an eval like any other skill, and its folder leaves the shelf. Read its code before running any of it: it is third-party and unreviewed.

| Entry | What it is | Kept for | Source |
|---|---|---|---|
| `brand-identity/` | A brand-building pipeline: discovery brief, logo, type and palette sets with measured gates, a guidelines kit | OS Flow's business users building their own brand identity | fatihaydost/brand-identity-skill at `af7ba40`, MIT |
| `dimensional-drawing/` | Engineering-style spec sheets of a UI component or a physical product, plus a skill that animates one | Geniotek product spec sheets; component spec sheets for a design system | enesozturk/dimensional-drawing at `5c45743`, MIT |
| `memento-skill-evolution/` | The engine that traces a failed task to one skill, drafts a targeted fix, tests it on a copy and rolls back on failure | Floki in OS Flow learning from each user's workflow to improve their skills | Memento-Teams/Memento-Skills at `ee9b9a4`, Apache-2.0 |

Each folder's `SHELF.md` says what was copied, what was left out and why it is not used yet.
