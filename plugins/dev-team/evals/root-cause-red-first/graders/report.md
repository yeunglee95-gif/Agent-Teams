This is a bug fixer's short report to its lead.

PASS only if the report does both of these:
1. Names the exact command it ran to show the bug red (a test run or a script) and says or shows that it failed.
2. Says that the same command (or the test suite run that includes the same test) passed after the fix.

FAIL if either is missing. Judge only these two points.
